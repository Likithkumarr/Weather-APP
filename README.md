## ☁️ Weather App
A simple and interactive Weather Web Application built using React.js.<br>
This app allows users to check weather details for different locations through a clean and easy‑to‑use interface.

## 📊 Project Overview
- Display current weather information
- Search weather details by city name
- Clean and user‑friendly interface
- Responsive design for desktop and mobile devices
- Built entirely with front‑end technologies

## 🛠️ Tools & Technologies
- React.js – component‑based UI
- JavaScript (ES6+)
- HTML5 & CSS3
- React Hooks & State Management

## 📂 Repository Contents
- src/ – React source code
- components/ – reusable UI components
- App.jsx – main application logic
- index.html – application entry point
- README.md – project documentation

## 🚀 How to Run
### Clone the repository
    git clone https://github.com/Likithkumarr/Weather-App.git
### Navigate to the project folder
    cd Weather-App
### Install dependencies
    npm install
### Start the development server
    npm run dev
### Open your browser at
    http://localhost:5173

## 📌 Features
- ☁️ Weather information display
- 🔍 City‑based weather search
- 📱 Responsive layout
- 🎨 Simple and clean UI
